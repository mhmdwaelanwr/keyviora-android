# KEYVIORA v2 — HONOR 50 device acceptance checklist

- [ ] Android Studio / GitHub Actions completes `:app:assembleDebug` with no errors.
- [ ] App installs and opens with dark theme, bottom navigation and brand icon.
- [ ] Open Accessibility settings and enable KEYVIORA Controls.
- [ ] Floating control appears; drag position persists after leaving/restarting app.
- [ ] Lock button turns the screen off. HONOR double tap to wake brings it back without a hardware key.
- [ ] Vol up / Vol down controls media volume, with on-screen Android volume feedback.
- [ ] Both volume sliders set actual media volume.
- [ ] Screenshot button takes a screenshot when the current app permits it.
- [ ] Flashlight permission request works; flashlight toggles on/off.
- [ ] Power button opens an KEYVIORA warning first; Cancel dismisses safely.
- [ ] The confirmed Power button opens Android's actual system power dialog.
- [ ] Home, Back, Recent apps navigate correctly.
- [ ] Notifications and Quick Settings open without reading or recording content.
- [ ] Wi-Fi, Bluetooth, Display, Sound open their respective settings screens.
- [ ] Changing accent, size and opacity immediately updates floating control.
- [ ] Single, double and long-press action assignments persist after app restart.
- [ ] Hide floating control works, and Style tab can restore it.
- [ ] Lock screen / accessibility overlay remain stable after screen wake and several hours in background.
- [ ] Enabling HONOR App Launch/background permissions improves persistence if OEM limits are present.
- [ ] Android permission settings show no Internet permission.

**Never intentionally power down the phone just to test the app if the physical power button is broken.**
